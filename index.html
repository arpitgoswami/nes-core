NES CORE.

An independent, open-source NES and Famicom emulator written in Rust. CPU, PPU, APU, memory bus, controllers, cartridge parsing and mappers - all implemented in this repository. No mocks, no wrappers around another emulator.

01 / PROGRESS

Where it stands.

A scale from 0 to 10, scored from working code and passing tests rather than from a plan. Six steps are closed, step seven is open.

65%
complete
level 6.5 of 10

Emulation works end to end. Accuracy is the open work.

Levels 1 to 6 are closed: a ROM parses, the 6502 executes, the PPU draws, the APU mixes, the desktop app runs, and 73 mapper ids switch banks. 90 tests cover that surface and CI is green on them.

Level 7 is timing accuracy. NTSC and PAL frame timing and the scroll pipeline are correct, but the PPU still composes a scanline in one step and MMC3 clocks its IRQ per rendered line instead of from an A12 watch. Levels 8 to 10 are input, compatibility testing and a real release.

Cartridge loading Closed

iNES and NES 2.0 headers parsed and validated, trainers skipped, mapper id resolved, unlisted mappers rejected with a clear error.

6502 core with every official opcode, common unofficial ones, page-cross and branch penalties, NMI, IRQ, reset and OAM/DMC DMA stalls.

Background, sprites in 8x8 and 8x16, scrolling, nametables, attributes, palettes, sprite 0 hit and vblank NMI.

Sound Closed

Two pulses, triangle, noise and DMC through a non-linear mixer at 44.1 kHz, wired to cpal. Compiled, not heard on this headless machine.

05

Desktop app Closed

Library, game view, settings, rebindable keys, achievements and 10 save-state slots per ROM in a versioned JSON format.

06

Mapper breadth Closed

73 mapper ids: 16 hand-written boards including MMC3, MMC5, VRC6 and TxSROM, plus 57 more through a shared extra-board engine.

07

Timing accuracy In progress

NTSC and PAL frame timing are right and the scroll pipeline was fixed after 0.5.0. Missing: per-dot PPU output and an exact MMC3 A12 IRQ filter.

Gamepad support, macOS and Linux builds, and a published v0.5.0 tag. The newest packaged binary is still the v0.3.0 Windows zip.

09

Compatibility Not started

Run a broad, legally redistributable ROM library and fix what breaks. No commercial game has been validated yet.

Per-dot PPU, rewind, netplay, NSF playback, builds for every platform, and a published compatibility table behind the claim.

04 / FEATURES

What works.

Status is deliberately conservative. Implemented means the code exists and is covered by tests.

iNES parser

Implemented

Validates signature, sizes and mapper. Reads NES 2.0 size nibbles. Skips trainers.

CPU (2A03)

Implemented

All official 6502 instructions, common unofficial ones, addressing modes, page-cross and branch penalties, NMI, IRQ, reset, DMA stalls.

Memory bus

Implemented

2 KB RAM mirroring, PPU, APU and controller registers, cartridge mapping.

PPU

Implemented

Background, sprites 8x8 and 8x16, scrolling, nametables, attributes, palettes, sprite 0 hit, vblank, NMI, emphasis.

APU

Implemented

Two pulses, triangle, noise, DMC playback, frame sequencer, frame IRQ, non-linear mixer at 44.1 kHz, plus MMC5 and VRC6 expansion audio.

Controllers

Implemented

Two standard controllers with correct strobe and shift behavior.

Mappers

Partial

73 ids. 16 hand-written boards (NROM, MMC1, UxROM, CNROM, MMC3, MMC5, AxROM, MMC2/MMC4, Color Dreams, VRC6, GxROM, Camerica, Quattro, TxSROM) plus 57 more through a shared extra-board engine. Unlisted ids report a clear error instead of guessing.

Audio output

Implemented

cpal on Windows and macOS. Runtime-loaded ALSA on Linux with no dev headers required.

Save states

Implemented

Versioned JSON format, ROM fingerprint check, 10 slots per ROM, atomic writes.

Settings and library

Implemented

Persisted in the per-user configuration directory.

GUI

Implemented

Dark desktop UI with library, game view, settings, save states, achievements, about.

Gamepad input

Not implemented

Keyboard only in this build.

PAL timing

Implemented

Header-detected PAL runs 312 scanlines at 3.2 dots per CPU cycle and 50.007 Hz.

Rewind, netplay, NSF

Not implemented

On the roadmap.

06 / ACCURACY

Honest boundaries.

What is exact and what is approximated, stated plainly.

Working

  • PPU advances dot by dot for timing
  • Register writes between scanlines work
  • Status-bar splits and scroll changes
  • MMC5 PRG, CHR, ExRAM, multiplier, IRQ
  • VRC6 PRG, CHR, mirroring, scanline and cycle IRQ
  • NTSC and PAL timing
  • Expansion audio per CPU cycle

Approximated or limited

  • PPU composes each visible scanline in one step
  • Per-dot mid-scanline tricks not emulated
  • Sprite overflow and sprite 0 hit approximated
  • MMC3 IRQ clocked per rendered scanline, not exact A12
  • MMC5 CHR banking at 1 KB granularity
  • MMC5 background substitution per screen tile
  • MMC5 split fine scroll uses SL-board path
  • PRG RAM write-protect registers stored, not enforced
  • MMC2 and MMC4 sprite-side latches do not fire
  • Quattro ignores Aladdin submapper swapped bits
  • Extra boards are banking only, no VRC7 or FME-7 audio
