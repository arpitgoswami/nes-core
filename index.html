03 / FEATURES

What works.

Status is deliberately conservative. Implemented means the code exists and is covered by tests.

iNES parser

Implemented

Validates signature, sizes and mapper. Reads NES 2.0 size nibbles. Skips trainers.

CPU (2A03)

Implemented

All official 6502 instructions, common unofficial ones, addressing modes, page-cross and branch penalties, NMI, IRQ, reset, DMA stalls.

Memory bus

Implemented

2 KB RAM mirroring, PPU, APU and controller registers, cartridge mapping.

PPU

Implemented

Background, sprites 8x8 and 8x16, scrolling, nametables, attributes, palettes, sprite 0 hit, vblank, NMI, emphasis.

APU

Implemented

Two pulses, triangle, noise, DMC playback, frame sequencer, frame IRQ, non-linear mixer at 44.1 kHz, plus MMC5 and VRC6 expansion audio.

Controllers

Implemented

Two standard controllers with correct strobe and shift behavior.

Mappers

Partial

0 NROM, 1 MMC1, 2 UxROM, 3 CNROM, 4 MMC3, 5 MMC5, 7 AxROM, 9 MMC2, 10 MMC4, 11 Color Dreams, 24 and 26 VRC6, 66 GxROM, 71 Camerica, 232 Quattro.

Audio output

Implemented

cpal on Windows and macOS. Runtime-loaded ALSA on Linux with no dev headers required.

Save states

Implemented

Versioned JSON format, ROM fingerprint check, 10 slots per ROM, atomic writes.

Settings and library

Implemented

Persisted in the per-user configuration directory.

GUI

Implemented

Dark desktop UI with library, game view, settings, save states, achievements, about.

Gamepad input

Not implemented

Keyboard only in this build.

PAL timing

Implemented

Header-detected PAL runs 312 scanlines at 3.2 dots per CPU cycle and 50.007 Hz.

Rewind, netplay, NSF

Not implemented

On the roadmap.

05 / ACCURACY

Honest boundaries.

What is exact and what is approximated, stated plainly.

Working

  • PPU advances dot by dot for timing
  • Register writes between scanlines work
  • Status-bar splits and scroll changes
  • MMC5 PRG, CHR, ExRAM, multiplier, IRQ
  • VRC6 PRG, CHR, mirroring, scanline and cycle IRQ
  • NTSC and PAL timing
  • Expansion audio per CPU cycle

Approximated or limited

  • PPU composes each visible scanline in one step
  • Per-dot mid-scanline tricks not emulated
  • Sprite overflow and sprite 0 hit approximated
  • MMC3 IRQ clocked per rendered scanline, not exact A12
  • MMC5 CHR banking at 1 KB granularity
  • MMC5 background substitution per screen tile
  • MMC5 split fine scroll uses SL-board path
  • PRG RAM write-protect registers stored, not enforced
  • MMC2 and MMC4 sprite-side latches do not fire
  • Quattro ignores Aladdin submapper swapped bits
